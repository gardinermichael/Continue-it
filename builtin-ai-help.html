    Manual Chrome checks

    • Manual
      Enable the on-device model flag

      Open chrome://flags/#optimization-guide-on-device-model, set it to Enabled, then relaunch Chrome.

    • Manual
      Enable the Prompt API flag

      Open chrome://flags/#prompt-api-for-gemini-nano, choose Enabled or Enabled multilingual, then relaunch Chrome.

    • Manual
      Check model download state

      Open chrome://on-device-internals, then check the Model Status tab for download progress or errors.

    • Manual
      Confirm supported device requirements

      Use macOS 13+ on desktop with either more than 4 GB GPU VRAM or at least 16 GB RAM and 4 CPU cores.

    • Manual
      Keep enough disk available for the Chrome profile

      Chrome documents at least 22 GB free for initial use and may remove the model if free space later falls below 10 GB.

    • Manual
      Use an unmetered network for the first model download

      The model runs locally after download, but Chrome needs an unmetered connection for the initial model fetch.
